# i18n

Pattern follows AnvilWiki: English has no URL prefix; other locales are prefixed.

| Locale | URL |
| --- | --- |
| `en` (default) | `/anime-vanguards/codes/` |
| `zh` | `/zh/anime-vanguards/codes/` |

## Sync these three places when adding a language

1. `src/i18n/routing.ts` — `locales` array
2. `src/locales/<locale>.json` — UI strings (missing keys fall back to English)
3. Routes under `src/pages/[locale]/` (or add the locale to `getStaticPaths`)

## What is translated today

- Nav, footer, home, codes chrome, legal pages, ads labels
- Codes data (`activeCodes`) stays in the English Markdown file so Wiki sync stays single-source
- Other guide bodies and blog posts fall back to English with a notice
