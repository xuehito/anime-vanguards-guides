## How to redeem Anime Vanguards codes

1. Launch **Anime Vanguards** on Roblox.
2. Open your **Profile** (sidebar on the right).
3. Open the **Codes** panel.
4. Paste a code and tap **Redeem**.
5. If it fails, check spelling, level requirements, and whether the code already expired.

Some codes require **Level 10** or **Level 30**. Level up in Story mode before redeeming those.

## FAQ

### Do Anime Vanguards codes expire?

Yes. Most event and milestone codes expire after a short window. Redeem ASAP.

### Are codes case-sensitive?

Usually yes. Use the **Copy** button and paste exactly.

### Why doesn't a code work?

Common reasons: already redeemed, expired, wrong spelling, not high enough level, or an old server (rejoin a fresh server and try again).

### Is this list official?

No. This is an unofficial fan site for fast redeem + next steps. Codes come from the developers; full history also lives on the [official Wiki Codes page](https://wiki.vanguards.gg/Codes).
