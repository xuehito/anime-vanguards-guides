Trait Rerolls change a unit’s trait for **1 RR per roll** (any rarity). Full currency page: [Wiki · Trait Rerolls](https://wiki.vanguards.gg/Trait_Rerolls). Rates: [Wiki · Traits](https://wiki.vanguards.gg/Traits) (Monarch **0.1%**, pity **1,500**).

Spend after you bank: [traits spend tree](/anime-vanguards/traits/#spend-decision-tree) · [reroll calculator](/anime-vanguards/trait-reroll-odds/). Where to click: [lobby guide](/anime-vanguards/lobby-guide/).

## This week — top 3 (most accounts)

Do these before chasing every shop line:

1. **Redeem [codes](/anime-vanguards/codes/)** the day they drop (pulse RR, often Level 30).  
2. **Clear RR challenges** (regular + daily + weekly) — highest “login and play” density for free RR.  
3. **Empty Boss Event + Rift shop RR lines** while the shops reset (Wiki: **4 Boss tokens = 1 RR**, **10 Rift Shards = 1 RR**).

Everything else (PvP, Guild, Odyssey, BP) fills the gaps when you have time — not before.

Coming back after a break? Use the [returning path](/anime-vanguards/returning-guide/) first.

## RR reality check (ignore the 7k flex)

| Claim you see | What’s usually true |
|---------------|---------------------|
| “I have 7k rerolls F2P” | Often **Robux bundles**, heavy event shiny → normalize, or multi-day macros — not a normal week |
| “Monarch in 200 rolls” | Possible; expected rate is **0.1%** with **pity 1,500** — use the [calculator](/anime-vanguards/trait-reroll-odds/) |
| Wiki “~854 RR / week” tables | **Upper-bound if you clear almost every renewable** (challenges, rifts, boss, bounties, quests…). Real casuals get a **slice** of that |
| Codes = infinite RR | Codes are **pulse** rewards; they expire. Bank them on a **main**, don’t spray fillers |

**Decision rule:** Plan spends around **codes + shops + challenges** you will actually finish. Do not empty life energy chasing creator inventories.

We do **not** teach macros or exploits. Play however you want; this page is honest **session priority**.

## When to run Odyssey (and when not)

| Situation | Do Odyssey? | Why |
|-----------|-------------|-----|
| You can clear early floors / adventure loop without constant wipes | **Yes** — good gems + RR side income | Returning guides and vets often call Odyssey the best “play a mode, bank resources” loop |
| You wipe on entry / need YT just to survive | **No — fix team first** | [Beginner](/anime-vanguards/beginner-guide/) or [returning](/anime-vanguards/returning-guide/) path; evo + one traited DPS beats forced Odyssey |
| Event free track / shop RR still unclaimed | **Event first**, Odyssey later | Limited currency expires; Odyssey usually returns next week |
| You only have 20–40 minutes | Challenges + dailies + shops **before** long Odyssey runs | Better RR per real-life minute for most accounts |

Lobby orientation: [lobby guide](/anime-vanguards/lobby-guide/). Live numbers and intensity caps: [Wiki · Odyssey](https://wiki.vanguards.gg/Odyssey) / Trait Rerolls page.

## Renewable sources (do these every cycle)

| Source | How | Notes (Wiki) |
|--------|-----|----------------|
| **Codes** | Redeem in Profile → Codes | Pulse — [active codes](/anime-vanguards/codes/) |
| **Daily Rewards** | Login calendar | Days 2/4 small RR; Day 7 larger |
| **Challenges** | Trait Reroll regular + Daily + Weekly | Dense free RR if you hop in on cooldown |
| **Boss Event Shop** | Boss tokens | **4 tokens = 1 RR**; ~8–9 clears for full shop stock (Wiki estimate) |
| **Rift Shop** | Rift Shards | **10 shards = 1 RR** |
| **PvP / Guild shops** | Mode coins | After core shops |
| **Odyssey / intensity** | Mode rewards | Daily caps exist — verify live; see table above |

## Limited / rotating sources

| Source | How |
|--------|-----|
| **Battle Pass** | Free + premium tracks |
| **Raid / Dungeon shops** | Tokens (dungeons often **30 = 1 RR** on Wiki) |
| **Event / Cursed / special shops** | Patch-limited — [event shop priority](/anime-vanguards/event/#event-shop-buy-order) |
| **Robux Trait Reroll Shop** | Real-money; **only this type is tradable** ([trading](/anime-vanguards/trading/)) |

## Practical weekly priority

1. Codes day-of.  
2. Challenges (regular/daily/weekly).  
3. Boss Event RR shop line.  
4. Rift RR shop line.  
5. Odyssey / PvP / Guild if time remains.  
6. Dump free RR into **one main DPS** — [spend tree](/anime-vanguards/traits/#spend-decision-tree).

## Trading note

- Grind / code / BP / exchange RR → generally **not** tradable.  
- **Robux shop RR** → tradable per Wiki.
