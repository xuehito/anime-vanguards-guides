Trait Rerolls change a unit’s trait for **1 RR per roll** (any rarity). Full currency page: [Wiki · Trait Rerolls](https://wiki.vanguards.gg/Trait_Rerolls). Rates for each trait: [Wiki · Traits](https://wiki.vanguards.gg/Traits) (e.g. Monarch **0.1%**, pity **1,500**).

Use the [reroll calculator](/anime-vanguards/trait-reroll-odds/) after you bank RR. Spend priority: [traits guide](/anime-vanguards/traits/). Where to click in lobby: [lobby guide](/anime-vanguards/lobby-guide/).

## Renewable sources (do these every cycle)

| Source | How | Notes (Wiki) |
|--------|-----|----------------|
| **Codes** | Redeem in Profile → Codes | Pulse rewards — [active codes](/anime-vanguards/codes/) |
| **Daily Rewards** | Login calendar | Days 2/4 give small RR; Day 7 larger (see Wiki Daily Rewards) |
| **Challenges** | “Trait Reroll” regular + Daily + Weekly | FAQ cites small daily/weekly packets — check in-game numbers |
| **Boss Event Shop** | Spend Boss Event tokens | **4 tokens = 1 Trait Reroll**; ~8–9 clears for full shop stock (Wiki estimate) |
| **Rift Shop** | Spend Rift Shards | **10 Rift Shards = 1 Trait Reroll**; aim several rifts/day for weekly cap |
| **PvP Shop** | PvP coins | From daily PvP quests / ranked |
| **Guild Shop** | Guild coins | Exchange in Guild Shop |
| **Odyssey / intensity loops** | Mode rewards | Wiki notes daily reroll limits around intensity loops (e.g. cap style limits) — verify live |

## Limited / rotating sources

| Source | How |

| **Raid / Dungeon shops** | Token exchange (dungeons often **30 tokens = 1 RR** on Wiki) |
| **Cursed Shop / event shops** | Patch-limited |
| **World Destroyer / special shops** | Patch-limited |
| **Robux Trait Reroll Shop** | Real-money; **only this type is tradable** ([trading rules](/anime-vanguards/trading/)) |

## Practical weekly priority

1. **Redeem codes** the day they drop.  
2. Clear **daily/weekly challenges** that pay RR.  
3. Run **Boss Event** enough for the RR shop line (4 tokens each).  
4. Run **Rifts** for shards → RR shop (10 shards each).  
5. Fill leftover with PvP / Guild / Odyssey as your account allows.  
6. Dump free RR into **one main DPS** — not five half-built units.

## Trading note

- **Grinded / code / BP / shop-exchange RR** — generally **not** tradable.  
- **Robux shop RR** — tradable per Wiki Trading / FAQ.  

Details: [Trading guide](/anime-vanguards/trading/).

## FAQ

### Where do I spend Trait Rerolls?

**Mandra (Traits) NPC** in the lobby **Upgrades** area. See [lobby guide](/anime-vanguards/lobby-guide/).

### How many RR for Monarch?

Wiki: **0.1%** per roll, **pity 1,500**. Use the [calculator](/anime-vanguards/trait-reroll-odds/) with Monarch selected.

### Is Boss Event or Rift better?

Both are core renewable sinks. Boss is token-efficient for shop RR; Rifts scale with how many you clear. Do **both** if you can — they use different currencies.
