**Evolution** turns base units into stronger forms with better kits. Mats and quests differ by unit — this guide focuses on **priority and process** so you do not farm the wrong map for a week.

Always confirm exact requirements on the unit’s evolution panel or the [official wiki](https://wiki.vanguards.gg/).

## Evolution priority (investment order)

| Order | Evolve this | Why |
|-------|-------------|-----|
| 1 | Main **DPS** you actually place every run | Biggest clear-time gain |
| 2 | Always-on **support / utility** | Team-wide value |
| 3 | Secondary clear / boss flex | Only after 1–2 are online |
| Later | Collection / index targets | When you are not blocked on content |

Cross-check with the [tier list](/anime-vanguards/tier-list/) so you do not fully evolve a C-tier placeholder.

## Before you farm materials

1. **Lock the target unit** — one main, not five half-evolved.  
2. Read the evolution requirements **in-game** (items, stages, quests).  
3. Finish free [codes](/anime-vanguards/codes/) so Trait Rerolls and currencies are available after the evo power spike.  
4. If you are brand new, skim the [beginner guide](/anime-vanguards/beginner-guide/) so Story progress unlocks farms.

## Efficient farming mindset

- Farm the **highest comfortable stage** that drops the mat you need (not the lowest spam if clear time is terrible).  
- Pair mat runs with account goals: XP, index, or event tokens when they stack.  
- Stop when the next evolution step is done — do not overfarm “just in case” stacks for units you will replace.

## Evolution vs traits vs summons

| Lever | When it wins |
|-------|----------------|
| **Evolve main** | Unit kit/scaling locked behind evo |
| **Trait main** | Already evolved, still feels weak |
| **Summon / banner** | You lack a viable main entirely |

Free code Trait Rerolls should go to the unit you are evolving long-term — see [traits guide](/anime-vanguards/traits/).

## Common mistakes

- Evolving every new pull “because I can”  
- Full evo on a unit the meta just power-crept  
- Ignoring support evo while only pumping a mediocre DPS  
- Burning event currency on cosmetics while evo mats are the real gate

## Simple weekly plan

1. Redeem codes → bank rerolls.  
2. Choose **one** evolution target for the week.  
3. Clear required quests / stages first (story gates first if needed).  
4. Farm mats until the next evo step completes.  
5. Trait that unit, then reassess stages you failed before.

## FAQ

### Should I evolve before traiting?

If evolution is cheap and unlocks a large kit upgrade, evolve first. If evo is expensive and the unit already has its full kit, traits can come first. In doubt: finish the next evo step if you are one farm away.

### Do shiny / skins affect evolution?

Cosmetic paths vary by game update. Never assume a skin replaces evolution — check the unit panel.

### Where do I see exact mats?

In-game evolution UI is source of truth; wiki pages help plan routes. This site stays focused on **who to evolve**, not scraping every mat table weekly.
