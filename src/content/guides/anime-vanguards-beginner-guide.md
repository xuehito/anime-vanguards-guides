New to **Anime Vanguards** on Roblox? This guide gets you productive in the first few sessions without wasting Gems or Trait Rerolls.

## 1. Claim codes first

Before long grinds, redeem every [active code](/anime-vanguards/codes/). Free Trait Rerolls and currencies stack up quickly around updates.

Some codes need **Level 30** — push Story until you unlock them, then redeem again.

## 2. Learn the loop

1. **Summon** units (gacha)
2. **Place** them along the enemy path (tower defense)
3. **Upgrade** during the match when you have economy
4. **Evolve** strong units with materials outside the match
5. **Reroll traits** on units you will keep

You lose if enemies reach your base often enough. Positioning and upgrade timing matter as much as rarity.

## 3. Early resource rules

- **Don't** blow all Gems on day-one banners without checking the [tier list](/anime-vanguards/tier-list/).
- **Do** invest materials into **one main DPS + one support/clear** first.
- **Trait Rerolls** are premium — save them for units with good base kits.
- Clear **Story / easier modes** for levels, index progress, and materials before hard events.

## 4. First team goals

Aim for a simple four-role core:

1. Reliable **DPS** (whatever best rarity you own)
2. **AoE** or multi-hit clear for dense waves
3. **Slow / utility** if available
4. Flex slot for bossing or economy

A mid-rarity team with good placement often beats a random high-rarity pile with no synergy.

## 5. Evolution & progression

- Check each unit's **evolution requirements** before farming the wrong map.
- Finish unit **index / bounty** style objectives when rewards are efficient.
- Rejoin fresh servers if UI or codes act stuck after updates.

## 6. Events & FOMO

Limited events (boss rush, dungeon, battle pass style rewards) are where veterans farm. As a beginner:

1. Finish main progression enough to survive the event entry stage
2. Use free codes tied to the event
3. Don't panic-spend if the new unit is not a clear upgrade for *your* account

## Common mistakes

| Mistake | Better habit |
|---------|----------------|
| Summoning every banner | Save for meta or pity goals |
| Rerolling traits on fillers | Only trait your long-term mains |
| Ignoring placement | Learn path choke points per map |
| Skipping codes | Redeem every update window |

Welcome to the grind — clear Story, bank resources, and upgrade only what you actually place every run.
