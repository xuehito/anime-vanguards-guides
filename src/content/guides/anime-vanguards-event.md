Limited **events**, dungeons, boss rushes, and battle-pass style tracks are where veterans farm and where new players often burn stamina. This guide is a **playbook**, not a live patch note — check in-game banners and [vanguards.gg](https://vanguards.gg/) for the current event name.

## What “event content” usually means

- Time-limited stages / dungeons  
- Boss rush or gauntlet modes  
- Event currencies and shops  
- Limited units, skins, or familiars  
- Codes tied to the update ([codes list](/anime-vanguards/codes/))

Mechanics change; the **decision order** below stays useful.

## Play order (most accounts)

| Step | Action | Why |
|------|--------|-----|
| 1 | Redeem **new codes** | Free rerolls/tokens for the patch |
| 2 | Unlock **entry requirements** (level / story) | Many event stages gate early |
| 3 | Clear **easy free rewards** first | Guaranteed value, low wipe risk |
| 4 | Push **harder tiers** only with a stable team | [Tier / investment](/anime-vanguards/tier-list/) |
| 5 | Spend event currency with the **buy order** below | Power > FOMO cosmetics if you are behind |

## Event shop buy order

Use this whenever a limited shop has more lines than you can finish. Exact prices change — **priority does not**.

| Priority | Buy first | Why |
|----------|-----------|-----|
| **1** | **Trait Rerolls** (or tokens that convert 1:1 into RR) | Permanent power; stacks with [farm path](/anime-vanguards/farm-trait-rerolls/) |
| **2** | **Evolution / progression mats** for a unit you will main | Unlocks kits before cosmetics |
| **3** | **Event unit fragments / pity pieces** if that unit is a real hole on your account | Only if you will place them post-event |
| **4** | Useful **consumables** (stat chips, essences you actually use) | After core power |
| **5** | Skins, flex mounts, pure cosmetics | Last — after free track and power lines |

**Skip or delay:** paying full premium currency for a unit that is already power-crept for *your* modes, or emptying gems on every banner “because event.”

Cross-check RR shop rates outside the event: [farm Trait Rerolls](/anime-vanguards/farm-trait-rerolls/). After you buy RR: [spend tree](/anime-vanguards/traits/#spend-decision-tree).

## Beginners: what to skip

If you are still on the [beginner path](/anime-vanguards/beginner-guide/):

- Do **not** empty gems on every event banner  
- Skip the hardest difficulty until you have one evolved + traited core  
- Grab free login / free track even if you cannot finish the event  
- Use the event as **farm practice**, not FOMO shopping  
- Returning after months? [Returning path](/anime-vanguards/returning-guide/) is faster than this page alone  

## Veterans: efficiency rules

1. Plan currency sinks **before** grinding endless stages (use the buy order).  
2. Evolve/trait the event unit only if it stays good post-event ([evolve](/anime-vanguards/evolve/), [traits](/anime-vanguards/traits/)).  
3. Re-check codes on day 1 and day 2 of the patch.  
4. If the event unit is not SS/S for your holes, treat the banner as optional.

## FAQ

### Do events replace Story farming?

Usually not. Story still matters for levels and unlocks. Events are **extra**.

### Should I save everything for the last day?

Risky. Secure free and easy rewards early; push hard content when ready.

### Where are exact stage guides?

Stage gimmicks change weekly. Use this site for **priority**; Discord / Wiki for boss callouts.
